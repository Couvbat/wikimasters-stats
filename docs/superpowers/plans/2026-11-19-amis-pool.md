# Amis par le pool — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** partager, au choix, sa collection et sa liste de souhaits avec le groupe par le pool, et voir automatiquement celles des autres dans l'onglet Amis.

**Architecture :**
- Le serveur gagne une table `profiles` et trois routes.
- Le script publie le profil du compte connecté après chaque relecture complète de la collection ou de la liste, si la case est cochée.
- Il lit les profils des autres en même temps que les prix (`poolPullMine`), et les range dans `db.friends` au format des fichiers ami, marqués `src: 'pool'`.

**Tech stack :** Node 24 (`node:sqlite`, `node:http`), userscript sans dépendance, `node:test`.

**Spec :** `docs/superpowers/specs/2026-11-19-amis-pool-design.md`

**Branche :** `claude/amis-pool`, partie de `main` (`e78c55f`).

## Global Constraints

- **Routes** (avec `x-group-key`) :
  - `POST /v1/profile` `{ id, pseudo, at, cards: [[carte, titre, rareté, exemplaires]…], wish: [[carte, titre, rareté]…] }` remplace le profil de cet `id` ;
  - `GET /v1/profiles` renvoie `{ profiles: [{ id, pseudo, at, cards, wish }] }` ;
  - `POST /v1/profile/remove` `{ id }`.
- **Limites** :
  - `id` : `okId` (80 caractères au plus) ; `pseudo` : 1 à 40 caractères ;
  - `cards` : 20 000 au plus (413 au-delà) ; `wish` : 5 000 au plus (413) ;
  - titre de 200 caractères au plus ; rareté `[A-Z]{1,3}` ou `null` ; exemplaires entiers de 1 à 9 999 ;
  - une entrée invalide donne 400 ; `at` est un nombre fini.
- **Versions** : serveur `1.2.0`, script `1.26.0`.
- **Textes du script** :
  - case : `'Partager ma collection et mes souhaits avec le groupe'` ;
  - sans pseudo : `'Écris d’abord ton pseudo dans l’onglet Amis.'` ;
  - marque dans la liste des amis : `' (via le pool)'` ;
  - bulle de « Retirer cet ami » pour un ami du pool : `'Il partage sa collection par le pool : il réapparaîtrait.'`.
- **Réglage** `db.pool.share`, `false` par défaut, commun à tous les comptes du navigateur.
- **Identité** : `db.userId` ; pseudo affiché : `db.me`. Le compte connecté est exclu des amis.

## Review Focus

1. **Case cochée sans pseudo** : rien n'est publié, la case se décoche, et le message le dit. Testé dans la tâche 2.
2. **Pool injoignable au moment de publier** : pas de plantage, et l'erreur est notée dans `db.pool.err` comme pour les prix. Testé dans la tâche 2.
3. **Deux comptes du même joueur** : le compte connecté est exclu, l'autre apparaît comme un ami. Testé dans la tâche 3.
4. **Un ami qui change de pseudo** (même `id`) : l'ancien nom disparaît, le nouveau apparaît. Testé dans la tâche 3.
5. **Profil mal formé, venu d'un vieux client ou d'ailleurs** : refusé par le serveur avec 400, et rien n'est enregistré. Testé dans la tâche 1.

### Task 3 : le script reçoit les profils des autres

**Files :** Modify `wikimasters-stats.user.js` (`poolPullMine` vers l. 1000, `importFriend` vers l. 2376, `renderFriends` vers l. 4132, bouton « Retirer cet ami » vers l. 2884) ; Test `test/amis-pool.test.js`

- Produces :

- Ajouter `'applyProfiles', 'poolPullProfiles'` à `EXPOSE`.

- [ ] **Step 1 : tests qui échouent** :

- [ ] **Step 3 : implémenter.**
